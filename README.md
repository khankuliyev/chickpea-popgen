# Популяционная структура нута по вставкам транспозонов

[Открыть отчёт Jupyter Notebook](report.ipynb)

Проверяем, воспроизводят ли генетический дрейф и простые модели миграции распределение аллелей в локусах транспозонов (TE) у нута. Сравниваем деревья региональных выборок при смене метрики расстояния и оцениваем согласие генетической и географической ординаций.

## Основные результаты

- В VCF было 190 образцов, в метаданных — 142. Анализ опирается на 141 совпавший образец из шести регионов и 123 185 аннотированных локусов.
- На основной панели AMOVA отнесла 1,74% вариации к различиям между регионами (перестановочное *p* = 0,0001), общий FST составил 0,0062.
- Ни одна из проверенных настроек трёх моделей Райта–Фишера не воспроизвела одновременно FST, долю приватных ALT и дисперсию региональных частот.
- Смена метрики изменила ближайшую пару в UPGMA. На основной панели топология Neighbor-Joining сохранилась при смене метрики, а при отборе локусов без пропусков изменилась.
- По 102 местам сбора сходство географической и двумерной генетической конфигураций было слабым. При перестановках внутри регионов свидетельств дополнительного географического соответствия не получено.

## Как открыть отчёт и воспроизвести расчёты

Для просмотра достаточно открыть [report.ipynb](report.ipynb). Таблицы и рисунки сохранены в выходах ячеек. Для выполнения нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook report.ipynb
```

По умолчанию ноутбук читает готовые таблицы и графики. Для полного пересчёта положите учебные файлы в каталог `data/` (создайте его командой `mkdir -p data`):

- `chickpea_TE.norm.vcf.gz` с генотипами TE.
- `Full_joint_SHORT.xlsx` с аннотациями локусов.
- `chickpea_data.xlsx` с идентификаторами, регионами и координатами образцов.

Затем установите `RECOMPUTE = True` в первой кодовой ячейке и выполните все ячейки. Расчёты сохраняют результаты в `results/` и занимают несколько минут. Скрипты находятся в `scripts/`. Для отдельного запуска используйте, например, `python scripts/stage1.py`. Порядок запуска — `stage1.py → plot_stage1.py → stage2.py → stage3.py → stage4.py → stage5.py → stage6.py`. Скрипты сохраняют промежуточную матрицу региональных частот и таблицу с координатами мест сбора локально. Исходные учебные файлы, промежуточная матрица и таблица с координатами исключены из Git.

## Интерпретация

`ALT` — альтернативный аллель в VCF. Соответствие этого аллеля присутствию вставки для всей панели не подтверждено. Оценки чувствительны к фильтрации по пропускам, отбору локусов при генотипировании и способу подсчёта расстояний. Моделирование проверяет ограниченную сетку условий, а географический тест описывает согласие двух первых осей ординации. Неопределённость модели и ограничения каждого этапа разобраны в отчёте.
